# Changelog

## 1.1.0
- BOX: KEY and SCALE fields (AUTO = the genre's scale, MAJOR, MINOR, all of GENRA's scales), the chords in the display,
  DUCK in front, UNDO / REDO of NEW, NEW ALL and genre changes, LOCK per track (the chord lock is now CHORDS).
- Projects: several songs; NEW, SAVE AS, RENAME, DUPLICATE, DELETE. The 1.0 session becomes PROJECT 1.
- GRID page: piano roll and drum grid, two bars at a time.
- PERFORM page: 16 effect pads, XY field, targets, mutes, DJ EQ with kills, FILL and BREAK.
- Ableton Link on SETUP (tempo, beat, start / stop, offset).
- Presets of FUNKE and SCHMELZ by sound (BASS, LEAD, PAD, KEYS, FX) as GENRA 2.41.

## 1.0.0
- First version: GENRA BOX (generator, four voices, presets, macros), ABLAUF MINI (parts, pads, song), a page for each
  synth (DRUM-X, GENRA MONO, FUNKE, SCHMELZ) with your own presets, UNDO, INIT and A / B, MIDI export, the session kept.
